Merlin's Cloak — screenshot harness

Every view below renders with FICTIONAL fixture data (see mocks/fixtures.ts) — no real router is contacted or required. Resize the browser viewport to 1280×800 before capturing Chrome Web Store screenshots. See README.md in this directory for details.

  • Popup — the toolbar popup (router address + read-only toggle).
  • Content UI — Dashboard — #/dashboard, the Network Map replacement.
  • Content UI — Connected Devices — #/clients, DHCP leases + live wireless stations.
  • Content UI — DHCP settings — #/dhcp, a representative declarative settings page.

The content UI is one hash-routed app (content.html#/<page-id>); any page id from src/pages/registry.ts can be loaded the same way, though only dashboard, clients and dhcp have fixture data tailored to them — other pages will render with blank fields rather than fixture values.
