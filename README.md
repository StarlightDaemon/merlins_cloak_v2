# Merlin's Cloak v2

This is the in-progress WXT + React rebuild (v2) of Merlin's Cloak, a
client-side re-theme of the AsusWRT-Merlin router web UI, built as a
Manifest V3 browser extension targeting Chrome and Firefox.

The original userscript at
[github.com/StarlightDaemon/merlins_cloak](https://github.com/StarlightDaemon/merlins_cloak)
remains the current stable version in the meantime.

**This repository is pre-release.** No router UI functionality has been
implemented yet - this is scaffolding only.

## Development

```bash
npm install
npm run dev          # Chrome
npm run dev:firefox  # Firefox
```

## Building

```bash
npm run build           # Chrome
npm run build:firefox   # Firefox
```
