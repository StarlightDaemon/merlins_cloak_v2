Merlin's Cloak v2

A modernized, client-side re-theme of the Asuswrt-Merlin router UI.

Same router, same settings, different front end. Talks only to your router — no accounts, no cloud, no tracking.

How to Install Pre-release (0.9.0-beta.1) View Source on GitHub

Read-Only by Default

Read-only by default

Explore safely. The extension ships with a read-only interlock switched on. You can browse every value the router exposes, but nothing can be written back until you deliberately turn the interlock off.

Your Data Stays Local

Every request is a same-origin request to your router. There is no analytics, no telemetry, no crash reporting, and no server operated by the developer. It rides your browser's existing authenticated session.

Extensive Coverage

73 views across every major settings and status category — Wireless, LAN, WAN, Firewall, VPN, QoS, USB apps, Parental Controls, AiProtection, DNS Director, and more.

Project Status & Compatibility

Current Maturity

This is a beta release. Read paths are broadly exercised. Write paths are implemented but almost entirely unverified against live hardware (except for one view). The read-only interlock defaults on for your safety.

Hardware Support

Live-verified Asuswrt-Merlin RT-BE92U.
Structurally sourced RT-AX88U, from a firmware source diff (untested on live hardware).
Untested, compatibility unknown other Wi-Fi 6, 6E, or 7 ASUS routers — no structural analysis has been performed on them.
Out of scope ROG or GT models. The extension is also built specifically against Asuswrt-Merlin, so stock ASUSWRT firmware isn't a target either.

Installation Guidance

Merlin's Cloak v2 targets Chrome and Firefox. It is currently in a developer preview state and is not yet published on the Chrome Web Store or Firefox Add-ons.

1

Build from Source

You will need Node.js. Clone the repository and run npm install followed by npm run build (for Chrome) or npm run build:firefox.

2

Load in Chrome

Open chrome://extensions, turn on Developer mode, click Load unpacked, and select the generated .output/chrome-mv3 folder.

3

Load in Firefox (Temporary)

Open about:debugging#/runtime/this-firefox, click Load Temporary Add-on…, and select the manifest.json file inside .output/firefox-mv3/. Note: Firefox installs do not survive a browser restart.
